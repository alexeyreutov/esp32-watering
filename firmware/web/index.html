Модули полива

Модуль № N отвечает на I²C-адресе 0x48+N−1 (перемычка ADDR на ADS1115: GND / VDD / SDA / SCL). Положение модуля в цепочке значения не имеет.

Влажность почвы, %

Точки — измерения, столбики снизу — полив (высота ∝ длительности). Пунктир — порог полива (если выбран один модуль).

Сон и Wi-Fi
Wi-Fi после кнопки, минБаза всегда спит и просыпается только на проверки — без Wi-Fi. Кнопка будит её с Wi-Fi; повторное нажатие или это время без активности (пока страница открыта, отсчёт не идёт) — снова сон. Полив таймаут не прерывает.
Синхронизировать время, раз в днейВо сне часы уходят примерно на 15 мин в сутки. Раз в N дней база при плановой проверке на ~5 с тихо подключается к роутеру за временем (без точки доступа и без значка). 0 — только при включении кнопкой.
