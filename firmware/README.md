# Прошивка базы автополива (PlatformIO)

Плата: **ESP32-C3 с OLED 0.42"** (72×40) — env `esp32c3`. Unit-тесты логики — env `native`. Распиновка — [`../docs/hardware/pins.md`](../docs/hardware/pins.md).

Если картинка на экране сдвинута или с мусором — у вас клон на SH1106: раскомментировать `-DWAT_OLED_SH1106=1` в `platformio.ini`.

```bash
pio test -e native     # src/core на хосте
pio run                # сборка
pio run -t upload      # прошивка по USB
pio device monitor     # лог 115200
```

Без локального PlatformIO — Docker, см. [`../AGENTS.md`](../AGENTS.md).

Первая прошивка — по USB (встроенный USB-JTAG/CDC; если порт не появляется — удерживать BOOT при подключении). **Во сне USB-порт пропадает**: для перепрошивки разбудить базу кнопкой или зажать BOOT и нажать RST. Дальше — через веб-интерфейс, «Система → Обновить прошивку», файл `.pio/build/esp32c3/firmware.bin`. Отдельный образ файловой системы заливать **не нужно**: LittleFS форматируется при первом старте, UI вшит в прошивку.

## Структура

```
firmware/
├── platformio.ini
├── partitions.csv             # 2 × OTA 1.625 МБ + LittleFS 640 КБ + coredump
├── web/index.html             # UI; доступен в прошивке как _binary_web_index_html_start
├── src/
│   ├── main.cpp               # порядок старта: насос OFF → LED → FS → конфиг → журнал → линия → режим пробуждения → экран
│   ├── app.h                  # общий контекст подсистем
│   ├── board_config.h         # пины и константы платы (синхронно с docs/hardware/pins.md и wiring.md)
│   ├── config.h/.cpp          # AppConfig ↔ config.json, валидация частичных обновлений
│   ├── core/                  # без Arduino, покрыто тестами:
│   │   ├── ads1115_regs.h     #   слова конфигурации ADS1115, трюк с клапаном на ALERT
│   │   ├── moisture.*         #   raw → %, калибровка, медиана
│   │   ├── battery.*          #   В → % для Li-ion
│   │   ├── schedule.*         #   «пора ли проверять», секунды до следующей проверки
│   │   ├── watering_policy.*  #   блокировки насоса, решение «поливать ли»
│   │   ├── power_policy.*     #   тревоги, длительность сна, когда синхронизировать NTP
│   │   └── event_codes.h      #   коды журнала (формат на flash)
│   ├── ads1115.*              # драйвер ADS1115 с проверкой записи чтением
│   ├── module_bus.*           # линия модулей: опрос, влажность, клапаны, восстановление I²C
│   ├── base_io.*              # насос, АКБ, датчик уровня, синий и красный LED, кнопка
│   ├── watering_controller.*  # неблокирующая последовательность клапан → насос → клапан
│   ├── garden.*               # состояние модулей, расписание, калибровка
│   ├── records.*, ring_store.*# история и журнал: кольцевые файлы в LittleFS
│   ├── time_keeper.*          # NTP, часовой пояс, время с браузера
│   ├── network.*              # STA + запасная точка доступа + captive DNS + mDNS
│   ├── web_ui.*               # HTTP API, OTA, отдача UI
│   ├── display.*              # OLED 72×40 (U8g2, программный I²C): экраны и значки
│   └── power_manager.*        # deep sleep, режимы пробуждения, сессия Wi-Fi, тревоги в RTC-памяти
└── test/test_core/            # Unity
```

## Индикация (синий LED на GPIO8)

| Мигание | Состояние |
|---------|-----------|
| короткая вспышка раз в 5 с | норма, подключено к Wi-Fi |
| 1 с горит / 1 с нет | работает точка доступа |
| горит постоянно | идёт полив |
| часто мигает | авария клапана |

Во сне синий LED выключен. Красный LED (GPIO4) — тревога «нет воды» / «низкий заряд», горит и во сне.

Кнопка пробуждения (GPIO3): во сне — разбудить с Wi-Fi. В сессии (GPIO3 или встроенная BOOT): короткое нажатие — сон, удержание 5 с — сброс Wi-Fi и перезагрузка в режим точки доступа. Нажатие во время планового пробуждения (без Wi-Fi) включает Wi-Fi.
